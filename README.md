# Wortklang · 德文單字

德文單字學習網頁：每個名詞含 **der / die / das** 冠詞、中文意思、例句，並可用瀏覽器語音聽標準德文發音。

## 功能

- **CEFR 分級**：A1（入門）與 A2（基礎），可切換等級學習
- 進度追蹤：標記「已學會」，顯示 A1／A2 完成百分比
- 單字瀏覽：依分類、冠詞篩選，或搜尋德文／中文
- 冠詞標示：陽性 der、陰性 die、中性 das（顏色區分）
- 例句：德文例句 + 中文翻譯
- 發音：聽單字／聽例句，另有慢速模式
- 閃卡練習：先聽再說出意思，再翻卡確認

## 開始使用

```bash
npm install
npm run dev
```

瀏覽器打開終端機顯示的本機網址（預設 `http://localhost:5173`）。

建議使用 **Chrome** 或 **Edge**，德文語音（de-DE）較完整。

## 建置

```bash
npm run build
npm run preview
```
