# Wortklang · 德文單字

德文單字學習網頁（A1→C1，約 **8000+** 詞）：每個名詞含 **der / die / das** 冠詞、中文意思、例句，並可用瀏覽器語音聽標準德文發音。

詞彙量對照（約）：A1 1100 · A2 1200 · B1 3000 · B2 1600 · C1 1200。

## 功能

- **CEFR 分級**：A1→C1，可切換等級學習
- 進度追蹤：標記「已學會」，顯示各級完成百分比
- 單字瀏覽：依詞性、冠詞篩選，或搜尋德文／中文
- 學習模式：瀏覽、閃卡、複數、動詞變化、字族
- 冠詞標示：陽性 der、陰性 die、中性 das（顏色區分）
- 例句：德文例句 + 中文翻譯
- 發音：聽單字／聽例句，另有慢速模式
- 文法輔助：複數規則、字首字根字尾、動詞變化、相關詞

## 開始使用

```bash
npm install
npm run dev
```

瀏覽器打開終端機顯示的本機網址（預設 `http://localhost:5173`）。

建議使用 **Chrome** 或 **Edge**，德文語音（de-DE）較完整。

## 建置

```bash
npm run build
npm run preview
```
